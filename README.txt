SISTEMA 3D 360 — OLYMPIKUS CORRE 4

Arquivo principal:
- index.html

Como usar:
1. Abra index.html no navegador.
2. No celular: arraste com o dedo para girar, faça pinça para zoom.
3. Clique nos botões Cabedal, Entressola, Solado, Contraforte e Placa / apoio.
4. Clique em "Baixar GLB" para exportar o modelo demonstrativo.

Como subir no GitHub Pages:
1. Envie o conteúdo desta pasta para seu repositório.
2. Ative GitHub Pages.
3. Abra o link do Pages.

Verdade técnica:
Este é um sistema 3D funcional em Three.js, com modelo reconstruído/procedural baseado nas fotos.
Ele não é fotogrametria perfeita. Para ficar idêntico milimetricamente ao tênis real,
substitua este modelo por um GLB escaneado em app de fotogrametria profissional.
