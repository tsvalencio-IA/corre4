Tênis One • Comparador 3D real com GLB

Comparador de tênis com modelo 3D real, ficha técnica e roteiro de venda

Esta versão usa arquivos 3D GLB/GLTF reais no navegador. O vendedor escolhe dois modelos, gira com o dedo, aproxima, ativa hotspots e compara a indicação de cada tênis.

Importante: o modelo 3D carregado por padrão é um GLB real de demonstração. Para ficar 100% fiel ao Corre 4, Corre Turbo, ASICS etc., substitua a URL do GLB pelo arquivo oficial/escaneado de cada produto. Sem o arquivo 3D oficial ou escaneamento/fotogrametria, nenhum HTML consegue mostrar o formato exato de um tênis específico.

Configuração da comparação

Escolha os produtos e, quando tiver os arquivos oficiais, cole a URL do GLB ou envie o arquivo localmente para testar.
